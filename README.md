# عملاء توتال

نظام متابعة عملاء **توتال لإدارة المرافق** — تطبيق ويب يعمل على الجوال والكمبيوتر ويُثبَّت كتطبيق (PWA).

إعداد وتصميم: **رامي هادي رياني** © 2026. جميع الحقوق محفوظة.

- الواجهة: HTML/CSS/JavaScript بدون خطوة بناء، تُستضاف على GitHub Pages.
- البيانات والدخول: Supabase (المشروع «نظام عملاء توتال»). الحماية عبر سياسات RLS؛ لا يرى البيانات إلا موظف فعّله المدير.
- `config.js` يحوي رابط المشروع والمفتاح العام (publishable) فقط.
